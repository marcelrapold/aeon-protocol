# ADR 0001 — Apache-2.0 license

- **Status:** accepted
- **Date:** 2026-08-09

## Context

The protocol only matters if other people and vendors adopt it. Adoption needs a permissive license; a protocol additionally benefits from patent safety for implementers.

## Decision

Apache-2.0 for the whole repository (specifications, schemas, fixtures, website).

## Consequences

- Permissive adoption, including commercial implementations.
- Explicit patent grant protects implementers.
- Attribution survives in derived works via the NOTICE mechanism if one is ever added.
